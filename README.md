✨ Abaya Luxe – Luxury Abaya E-Commerce Website
Overview

Abaya Luxe is a premium, static e-commerce website showcasing luxury abayas. Designed with a minimalist aesthetic and a Black/Gold/Ivory palette, the site is fully responsive and optimized for mobile devices. Built using HTML5, CSS3, and Vanilla JavaScript, it offers a smooth, interactive user experience.

📂 Project Structure
abaya-luxe/
├── index.html           # Home page
├── shop.html            # Product listing
├── product.html         # Product details
├── about.html           # About the brand
├── contact.html         # Contact form
├── css/
│   └── main.css         # Global styles
├── js/
│   └── script.js        # Interactive functions
└── assets/
    └── images/          # Product images & icons

🌟 Key Features

Home Page: Hero section with tagline “Elegance in Modesty”, featured collections, and testimonials.

Shop Page: Product grid with filters for categories, colors, and price.

Product Details: Image gallery, size selection, and Add to Cart UI.

About Page: Brand story emphasizing elegance, modesty, and confidence.

Contact Page: Simple contact form with social links.

Design & Interactions:

Typography: Playfair Display (Headers) & Inter (Body)

Lucide icons for clean look

Sticky navbar, hover effects, interactive elements

Mobile-first: Fully responsive design for smartphones & tablets.

💻 Tech Stack

Frontend: HTML5, CSS3, JavaScript

Fonts: Google Fonts – Playfair Display & Inter

Icons: Lucide Icons

Design Philosophy: Minimalist, luxury, Islamic-inspired subtle aesthetics

🚀 How to Run

Locate the project folder on your computer (abaya-luxe/).

Open index.html in any modern browser (Chrome, Firefox, Edge).

No server or installation required – fully static website.

Optional: Test mobile responsiveness using browser dev tools (Toggle Device Toolbar).

🎨 Customization

Replace placeholder images in assets/images/ with high-resolution product photography.

Update prices to local currency (PKR) or desired format.

Add a favicon (.ico or .png) for the browser tab.

📌 Notes

Static website; no backend functionality.

Add real payment or cart features if deploying live.

Maintains luxury, minimalistic aesthetics across all pages.
